# Course Studio Guide

Use Course Management to create, filter, clone, submit, approve, publish or archive courses. Studio uses a three-level outline: section → subsection → unit → component.

## Authoring workflow

1. Create course metadata.
2. Add sections, subsections and units.
3. Add components to units.
4. Link media/package/file components to repository items.
5. Run validate publish.
6. Submit review, approve and publish.

## Repository workflow

Repository authors can create folders, upload files, add new versions, move/copy/share items, review metadata, get download URLs and submit items for approval. Files are deduplicated by checksum when possible.
