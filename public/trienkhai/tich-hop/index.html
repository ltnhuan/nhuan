Phân hệ Tích hợp & vận hành

Chi tiết triển khai theo chức năng

Tập trung vào nền tảng hệ thống: tenant, IAM, SIS, API, webhook, backup và kiểm soát vận hành.

Luồng tổng thể

Luồng vận hành an toàn theo dự án

  1. Thiết lập tenant, campus, user, role, permission.
  2. Kích hoạt tích hợp SIS/API và kiểm tra mapping dữ liệu.
  3. Đưa dữ liệu sản xuất theo job đồng bộ và xử lý conflict.
  4. Giám sát webhook, audit log và thiết lập backup/rollback.
  5. Vận hành theo kế hoạch UAT – go-live.

Chi tiết từng chức năng

Bản đồ chi tiết triển khai

1. Tenant và tổ chức

Quản lý phân vùng tenant và cấu hình mặc định theo đơn vị.

Bước làm

  • Tạo tenant và mã định danh.
  • Cấu hình branding + quyền mặc định.
  • Kiểm tra dữ liệu không lẫn tenant.

Ý nghĩa

Cho phép mở rộng multi-tenant và kiểm soát dữ liệu.

Liên hệ module khác

  • Role & permission
  • Audit log
  • Go-live

2. User / Role / Permission

Điều phối phân quyền người dùng theo chức năng.

Bước làm

  • Import user, gán role.
  • Kiểm soát action registry.
  • Kiểm tra UI/API policy theo actor.

Ý nghĩa

Hạn chế rủi ro truy cập sai hoặc thao tác trái quyền.

Liên hệ module khác

  • Course management
  • Đánh giá
  • User/Role

3. SIS Integration

Đồng bộ học viên, lớp, khóa, điểm và điểm danh theo hệ thống nguồn.

Bước làm

  • Cấu hình nguồn + mapping.
  • Test sync thử.
  • Giải quyết conflict trước production.

Ý nghĩa

Đảm bảo dữ liệu nhất quán với HRM/SIS hoặc hệ thống học vụ.

Liên hệ module khác

  • Enrollment
  • Gradebook
  • Webhook

4. API v1 / Catalog

Cung cấp endpoint cho tích hợp portal, mobile, BI.

Bước làm

  • Kiểm tra /integration-api/catalog.
  • Đồng bộ openapi và key policy.
  • Thông báo version cho đội ngoài.

Ý nghĩa

Rút gọn chi phí tích hợp mới và giảm lỗi API sai version.

Liên hệ module khác

  • Course
  • Question bank
  • BI / Analytics

5. Webhook inbound/outbound

Nhận và đẩy sự kiện giữa LMS và hệ sinh thái ngoài.

Bước làm

  • Khai báo endpoint và secret.
  • Gửi thử sự kiện.
  • Theo dõi delivery và retry.

Ý nghĩa

Bảo đảm đồng bộ gần thời gian thực giữa nhiều hệ thống.

Liên hệ module khác

  • Audit log
  • Điểm/grade events
  • Monitoring

6. Audit & vận hành

Ghi log truy vết và quản lý vận hành an toàn.

Bước làm

  • Thu thập log theo actor/action.
  • Phân quyền truy xuất theo vai trò.
  • Đặt retention + backup kiểm định.

Ý nghĩa

Hỗ trợ điều tra sự cố, tuân thủ và audit.

Liên hệ module khác

  • Go-live checklist
  • UAT
  • Security + API

Lưu ý nghiệm thu

Điều kiện an toàn khi đưa hệ thống lên production

Mỗi kịch bản vận hành phải có log, retry, phân quyền và cơ chế rollback rõ ràng để chứng minh khả năng phục hồi sau lỗi tích hợp.
