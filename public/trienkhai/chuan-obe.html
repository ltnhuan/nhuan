Phân hệ Chuẩn & OBE

Chi tiết triển khai theo chức năng

Phân hệ đảm bảo dữ liệu học tập liên kết chuẩn đầu ra và minh bạch cho công tác kiểm định.

Luồng tổng thể

Từ xác định outcome đến minh chứng kiểm định

  1. Thiết kế PLO/CLO + khung năng lực theo chương trình.
  2. Gắn outcome cho khóa học, câu hỏi, bài tập, hoạt động.
  3. Chạy khảo sát điểm coverage theo lớp, khóa và chương trình.
  4. Tạo báo cáo evidence theo kỳ kiểm định.
  5. Phát hành dữ liệu cho dashboard và lưu dấu truy xuất.

Chi tiết từng chức năng

Thực thi chi tiết theo module chuẩn

1. Outcome management

Quản lý PLO/CLO theo cấp cơ sở, chương trình, khóa học.

Bước làm

  • Định nghĩa outcome + mã code chuẩn.
  • Ánh xạ vào hoạt động đánh giá/lộ trình.
  • Xác nhận sự đồng bộ theo kỳ học.

Ý nghĩa

Tạo nền tảng đo lường thành quả đào tạo theo chuẩn chất lượng.

Liên hệ module khác

  • Outcome matrix
  • Question bank
  • Course Studio

2. Outcome matrix

Tính coverage và phát hiện khoảng trống so với mục tiêu đầu ra.

Bước làm

  • Build ma trận mapping.
  • Tính coverage theo trọng số.
  • Đánh dấu gap theo lớp/chương trình.

Ý nghĩa

Nhìn thấy nhanh lớp/môn nào chưa đáp ứng mục tiêu đầu ra.

Liên hệ module khác

  • Gradebook
  • SCORM/xAPI/LTI
  • Dashboard quản trị

3. Competency framework

Xây khung năng lực và gán kỹ năng theo hồ sơ người học.

Bước làm

  • Định nghĩa competency taxon.
  • Tạo thang đánh giá thành phần.
  • Cập nhật learner skill record.

Ý nghĩa

Hỗ trợ đào tạo theo năng lực thay vì chỉ điểm số.

Liên hệ module khác

  • Portfolio
  • Assignment
  • Accreditation

4. Accreditation report

Tổng hợp evidence, cải tiến, lộ trình khắc phục theo chuẩn.

Bước làm

  • Tạo bộ evidence theo chỉ số.
  • Tạo plan cải tiến cho gap.
  • Xuất báo cáo theo template yêu cầu.

Ý nghĩa

Rút ngắn thời gian chuẩn bị hồ sơ kiểm định.

Liên hệ module khác

  • Outcome matrix
  • Dashboard
  • Audit log

5. SCORM, xAPI, LTI

Kết nối nội dung/chứng thực học tập ngoài hệ sinh thái LMS.

Bước làm

  • Upload/đăng ký package.
  • Cấu hình launch & security.
  • Thu event và đồng bộ chỉ số.

Ý nghĩa

Bảo đảm tương thích chuẩn quốc tế và theo dõi hành vi học tập chuẩn hóa.

Liên hệ module khác

  • Video
  • Analytics
  • API
