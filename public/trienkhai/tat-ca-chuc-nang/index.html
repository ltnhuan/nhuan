Ma trận chức năng

Chi tiết toàn bộ chức năng triển khai EraLMS

Mỗi dòng mô tả mục tiêu nghiệp vụ, màn hình hoặc API liên quan và kết quả cần nghiệm thu khi đưa vào vận hành.

Luồng thực thi khi triển khai

Chuỗi triển khai chuẩn từ lõi đến vận hành

  1. Khởi tạo core admin: tenant, campus, user, role, permission.
  2. Kế hoạch nội dung: khóa học, học liệu, câu hỏi, rubric, outcome.
  3. Triển khai luồng người học: ghi danh, lộ trình, attendance, cộng đồng.
  4. Gắn AI/analytics và chuẩn hóa báo cáo theo vai trò.
  5. Tích hợp hệ thống ngoài, audit và kiểm tra UAT trước go-live.

Ý nghĩa nghiệp vụ

Mẫu vận hành sử dụng cho đội dự án và khách hàng

Mục tiêu

Hỗ trợ đọc nhanh toàn bộ năng lực của EraLMS theo nhóm, tránh mất thời gian tìm kiếm qua tài liệu rời rạc.

Đào tạo và học liệu

Thiết kế, phát hành và theo dõi khóa học

Quản trị khóa học

Tạo danh mục, khóa học, phiên bản, thông tin mô tả, owner, trạng thái draft/review/published/archived.

Màn hình
/courses, /courses/studio
API
Course API, repository API, publish checklist.

Course Studio

Soạn section, unit, component, rich text, tài liệu, quiz nhúng, rule hoàn thành, preview và lịch sử chỉnh sửa.

Đầu vào
Đề cương, CLO/PLO, học liệu, rubric.
Đầu ra
Khóa học xuất bản có cấu trúc và tracking hoàn thành.

Kho học liệu

Lưu file, phân loại, versioning, phê duyệt nội dung, tái sử dụng tài nguyên và kiểm soát quyền truy cập.

Nghiệm thu
Upload, thay thế, duyệt và gắn học liệu vào bài học không mất phiên bản cũ.

Video platform

Quản lý video asset, rendition, phiên xem, watch event, anti-fake, tiến độ xem và video analytics.

Màn hình
/videos, /videos/lesson, /videos/analytics

Learning path

Thiết kế rule mở khóa, điều kiện hoàn thành, tiến độ cá nhân, tiến độ lớp và gợi ý bước học tiếp.

Nghiệm thu
Người học chỉ mở được nội dung khi đạt điều kiện đã cấu hình.

Mobile learning

Manifest PWA, offline queue, offline progress, đồng bộ dữ liệu sau khi có mạng và ưu tiên nội dung trên di động.

Đầu ra
Người học dùng được các luồng học tập cơ bản trên màn hình nhỏ.

Người học

Hành trình học, tương tác và hồ sơ năng lực

Enrollment

Ghi danh theo lớp, cohort, import danh sách, trạng thái học, lịch sử ghi danh và đồng bộ SIS.

Attendance

Buổi học, check-in sinh viên, bảng điểm danh giảng viên, live session, thời lượng tham gia và điều kiện dự thi.

Community

Forum, nhóm học tập, discussion thread, reaction, mention, notification và moderation report.

Survey & QA

Survey form, question, campaign, response, evidence file và improvement action sau khảo sát.

Career portfolio

Hồ sơ năng lực, portfolio item, timeline, public portfolio, employer view và digital twin IDP.

Digital credential

Badge builder, certificate builder, issue job, wallet, verification portal và credential event log.

Tích hợp và API

Kết nối EraLMS với hệ sinh thái hiện có

SIS Integration Hub

Integration system, mapping center, sync job, conflict, event log, adapter và cấu hình hệ thống nguồn.

API v1

API cho core, course, repository, question bank, exam, assignment, gradebook, attendance, credential, analytics.

Webhook

Inbound webhook nhận sự kiện từ hệ ngoài; outbound webhook phát sự kiện LMS sang portal, CRM, BI hoặc DWH.

Security integration

API key, tenant header, demo auth, permission middleware, policy và audit cho request quan trọng.

Vận hành

Kiểm thử, go-live và duy trì hệ thống

System check

Kiểm tra migration, seed, API health, queue, cache, storage, quyền truy cập và dữ liệu demo.

Action check

Đối soát action registry, luồng tạo/sửa/xóa/duyệt trong từng module và trạng thái hoàn thành.

UAT

Kịch bản nghiệm thu theo vai trò: admin, giảng viên, người học, khảo thí, học vụ, kiểm định và IT.

Backup và rollback

Kế hoạch sao lưu dữ liệu, file học liệu, cấu hình, kiểm tra khôi phục và quy trình xử lý sự cố.
